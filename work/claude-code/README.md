# Claude Code 复核工作区

本目录存放 Claude Code 的产出：复核意见、公约审查、提案。每个任务一个子目录：`work/claude-code/<任务编号>/`。

**复核工作的完整规则（文件隔离、状态流转、打回流程）见仓库根目录 [`AGENTS.md`](../../AGENTS.md)。**

> 本文件**不复述规则**，只说明本目录放什么。
> 原因：规则复述在多处时，每次改规则都会漏掉几份 —— 本文件就曾因此残留过 v1.1 已废弃的「打回后保持 done」说法。

## 本目录内容

| 路径 | 说明 |
|---|---|
| `<任务编号>/review.md` | 该任务的复核意见 |
| `protocol-review-*.md` | 对协作公约本身的审查报告 |
| `proposal-*.md` | 向 Lo 提交的提案（非任务） |

## 规则

- **不得直接修改 `work/codex/` 下的文件** —— 复核意见一律写在本目录。
- 写入范围与例外，见 `AGENTS.md` §3。
